## Выполнено

### Аудит кода (ноябрь 2026)

- Импорт share-кода больше не доверяет `id`: сопоставление по relay/адресу,
  предупреждение об обновлении существующего сервера, тест на hijack.
- «Подключиться» перепривязывает открытый чат к выбранному серверу; состояние
  сервера и чата больше не расходится.
- `AppData.migrate`: старые схемы обновляются, данные от более новой версии не
  перезаписываются (read-only).
- `PluginClient` закрывает HTTP-клиенты; `SyncBundle` и share-коды используют
  общий `decodeGzipLimited` против gzip-бомб.
- Relay-токен отделён от plugin-токена (старые профили мигрируют один раз),
  relay требует HTTPS кроме loopback.
- Seed синхронизации хранится в `SecretStore`, старый `identity.json`
  мигрирует и удаляется.
- `newId()` использует `Random.secure()`; окно timestamp синхронизации — 5 мин.
- Windows-установщик передаёт `LM_CHAT_WINDOWS_PUBLISHER` в `--dart-define`;
  подписанная сборка без издателя не собирается.
- CI: Windows release, Python self-tests, порог покрытия 50%, release APK с
  проверкой подписи, CodeQL для Go, actions закреплены по SHA.
- UI: троттлинг стрима (50 мс), `RepaintBoundary`, `Selector` по
  `AppState.revision`; `HomeScreen` не перестраивается целиком на каждый чанк.
- Разбиты большие файлы: `app_state.dart` 2 650 → 1 843
  (`app_state_transfer.dart`), `settings_screen.dart` 1 826 → 1 190
  (`server_edit_dialog.dart`), `home_screen.dart` 2 340 → 1 738
  (`chat_drawer.dart`).
- Добавлены тесты: импорт share-кода, выбор модели, настройки запуска, варианты
  ответа, диагностика, экран синхронизации, полнота английских переводов.
- Итоговая проверка: `flutter analyze` — чисто, **292/292** теста, Windows
  release и APK собираются, CI/CodeQL зелёные.
