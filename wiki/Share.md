# Поделиться сервером

Сервер можно передать на другое устройство одним кодом — без ручного ввода
адресов, ID устройства и ключей.

**Настройки → Серверы**:

- иконка **«Поделиться»** у сервера — один сервер;
- иконка **«Поделиться всеми»** в заголовке раздела — все серверы сразу.

Код имеет вид `LMSRV1.…` (один сервер) или `LMSRVS1.…` (несколько). На Android
его можно показать как QR-код и сразу отсканировать камерой; на Windows камеры
нет, поэтому код вставляют вручную.

## Варианты

- **Без relay** — остаётся только локальный адрес LM Studio. Подходит для
  устройств в одной сети.
- **С relay** — в код попадают адрес relay, ID устройства, настройки E2E и
  токен relay. Подходит для доступа снаружи.

## Токен relay

Если у сервера задан токен relay, вариант **«С relay»** включает его в код.
Перед показом QR приложение требует подтвердить, что вы понимаете риск: любой,
у кого есть код, получает доступ к relay.

Если токен не задан, код всё равно можно передать — получатель введёт токен
вручную.

Никогда не передаются: API-токен LM Studio, токен моста и токен плагина.
Токен плагина не подставляется вместо пустого токена relay.

## Импорт

1. **Настройки → Серверы → + → «Импортировать по коду»**.
2. Вставьте код (на Windows — кнопка **«Вставить»**).
3. Проверьте список серверов и нажмите **«Импортировать»**.

На Android в том же меню есть **«Сканировать QR»**.

Импорт не создаёт дубликаты: сервер сопоставляется по ID, адресу relay или
локальному адресу. Существующие локальные токены не перезаписываются —
заполняются только пустые поля. Токен relay из кода сохраняется в системном
хранилище секретов.

## QR или код

Если код помещается в QR (до 1800 байт), показывается QR. Для большого списка
серверов QR не помещается — используйте копирование кода или системное
«Поделиться».
