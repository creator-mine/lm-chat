# Синхронизация по локальной сети

Два устройства могут объединить чаты и серверы без облака и без плагина. Оба
приложения должны быть открыты в одной сети.

## Сопряжение

1. На обоих устройствах: **Настройки → Синхронизация по локальной сети** →
   включите синхронизацию.
2. Нажмите **«Найти устройства»** на одном из них.
3. Выберите второе устройство.
4. Сравните **8 цифр** на двух экранах и нажмите «Совпадает» на обоих.

Если UDP-поиск не работает (VLAN, firewall, AP isolation), нажмите **«По
адресу»** и введите `IP:порт`, который показывает второе устройство. Порты:
UDP `45872` для поиска, TCP `45873` для обмена. Если TCP-порт занят, приложение
выберет случайный и покажет его.

## Что переносится

- чаты, сообщения, варианты ответов, tool calls и вложения;
- серверы LM Studio без API-токенов и токенов моста/плагина/relay.

Не переносятся: токены, шаблоны промптов, оформление, настройки генерации и
удаления. Удалённый на одном устройстве чат вернётся, если он есть на другом.

## Объединение

- Чаты и сообщения объединяются по `id`.
- При конфликте правки побеждает более новый `editedAt`, а проигравший текст
  сохраняется как вариант ответа.
- Локальные настройки серверов и токены не перезаписываются; недостающие
  серверы добавляются, `serverId` в чатах перепривязывается.
- Чаты с активной генерацией не синхронизируются.

## Автосинхронизация

При включённой синхронизации обмен запускается при старте приложения, если
спаренное устройство онлайн. Кнопка **«Синхронизировать»** запускает поиск и
обмен вручную. При возврате из фона автосинхронизации нет — только listener.

## Безопасность

Обмен идёт по локальной сети, но содержимое чатов шифруется X25519 +
HKDF-SHA256 + AES-256-GCM. Ключи устройств закрепляются после сопряжения.
Принимаются только приватные адреса. Незнакомое устройство не получает данные.
В лог попадают только устройство, размер и количество изменений.

## Ограничения

- Оба приложения должны быть открыты.
- Android слушает только на переднем плане.
- На Windows при первом запуске нужно разрешить входящие подключения в
  брандмауэре.
- Устройства должны быть в одной сети.

Если сеть недоступна или нужно передать сервер с relay, используйте
[«Поделиться сервером»](Share) — код или QR без синхронизации.
